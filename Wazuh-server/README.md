# Wazuh Lab Environment

Professional lab setup for deploying, configuring, and testing **Wazuh** (open-source XDR and SIEM platform) with multi-OS endpoints.

## Overview

This laboratory environment demonstrates a complete Wazuh deployment consisting of:

- **Wazuh Manager** (and optionally Indexer + Dashboard) running on Ubuntu
- **Wazuh Agent** installed on Ubuntu
- **Wazuh Agent** installed on Windows 10

The lab is designed for security monitoring, threat detection, log analysis, file integrity monitoring (FIM), vulnerability detection, and compliance testing in a controlled environment.
